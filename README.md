# Dockerfile (dockerfile)
A text file that contains instructions for building Docker container images, defining the application environment, dependencies, and configuration in a reproducible way. Dockerfiles accelerate software delivery cycles and improve collaboration between development and operations teams.

## APIs

Dockerfile is a declarative text-based build specification, not a REST API. Therefore no OpenAPI specification is published. Reference: [Dockerfile reference](https://docs.docker.com/reference/dockerfile/) for instructions such as `FROM`, `RUN`, `CMD`, `ENTRYPOINT`, `COPY`, `ADD`, `ENV`, `WORKDIR`, `EXPOSE`, `USER`, `VOLUME`, `ARG`, and `LABEL`.
